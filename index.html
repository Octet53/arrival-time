🚀 Cloudflare Workers + D1 自動化收集架構

  1. 預設資料庫網址：https://hk-bus-history.clear-octet53.workers.dev/
  2. 單一路線按需讀取端點：/routes/{營運商}_{路線}.json（例如 /routes/LWB_A43P.json）
  3. 定時收集端點：/collect（由 Cron Trigger 每 10 分鐘自動抓取政府實時 API 並以 7 日滾動指數平均更新各站段秒數）。
